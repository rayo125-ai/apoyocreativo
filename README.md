# Apoyo Creativo — Arequipa, Perú

Landing page estática en HTML, CSS y JavaScript, lista para GitHub Pages.

## Publicar en GitHub Pages

1. Crea un repositorio público en GitHub (por ejemplo, `apoyo-creativo`).
2. Sube **el contenido de esta carpeta a la raíz del repositorio**: `index.html`, `style.css`, `script.js` y la carpeta `assets/`.
3. En GitHub, entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/ (root)`, y guarda.
5. Espera a que GitHub indique la URL publicada. Normalmente será `https://TU-USUARIO.github.io/apoyo-creativo/`.

No necesitas instalar dependencias ni usar npm. El sitio utiliza rutas relativas, compatibles con repositorios de GitHub Pages.

## Personalizar

- `index.html`: textos, servicios, enlaces y metadatos.
- `style.css`: diseño, colores y adaptación móvil.
- `script.js`: galería, navegación y formulario de WhatsApp.
- `assets/`: logotipo y fotos de proyectos.

**Contacto configurado:** +51 958 744 709 (`51958744709` en WhatsApp). **Zona de atención:** Arequipa, Perú, exclusivamente.

El formulario prepara el mensaje y abre WhatsApp para que el visitante lo envíe. No almacena datos ni necesita servidor.

Para mejorar las vistas previas al compartir en redes, configura una URL absoluta para `og:image` una vez que conozcas el dominio definitivo. No añadas un `canonical` hasta tener esa URL.
